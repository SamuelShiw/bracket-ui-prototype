# BRACKET UI Prototype

Prototipo visual independiente para la evolución UI/UX del sistema BRACKET.

## Objetivo

Este repositorio **no reemplaza ni modifica** el sistema funcional desplegado. Su propósito es validar dirección visual, experiencia tablet-first y flujos clínicos antes de integrar cambios al producto real.

## Alcance del prototipo v1

- App shell tablet-first
- Dashboard operativo
- Agenda visual
- Pacientes
- Atención clínica
- Odontograma esquemático FDI
- Estados y componentes base del design system

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Lucide React

## Principios

- Clinical Luxury / iPad Native
- Contexto antes que navegación
- Touch antes que densidad extrema
- Claridad antes que decoración
- Sin datos reales de pacientes

> Prototipo UI. Todos los datos visibles son demostrativos.
